XuperTV para Hisense VIDAA U9 — versión 1.0.1

OBJETIVO
Fuente de aplicación web HTML5 preparada para pruebas en televisores Hisense VIDAA, con perfil visual 1920x1080 y controles remotos direccionales.

OPTIMIZACIONES PARA EL HISENSE 50A65NV
- Navegación con flechas, OK/Enter y regreso (incluye códigos de tecla Back comunes en VIDAA).
- Catálogos grandes cargados por bloques de 48 fichas para reducir el trabajo inicial de renderizado.
- Imágenes con carga diferida; favoritos e historial locales.
- Interfaz 16:9, con distribución adaptable y foco visible para control remoto.

CONTENIDO
- 638 fichas combinadas de las fuentes Roku y webOS.
- La captura de catálogo no contiene enlaces de reproducción para la mayoría de las fichas.
- Los proyectos recibidos no proporcionaron una lista de canales en vivo ni credenciales de portal. Por eso no se inventan canales ni enlaces.
- La reproducción HTML5 solo funcionará con URLs reales y formatos/servidores compatibles con el firmware.

PRUEBA
1. Publica esta carpeta en un servidor HTTP/HTTPS accesible desde la TV. Para probar en una red local puedes iniciar `python -m http.server 8080` desde esta carpeta y usar la IP de tu PC:8080.
2. En el navegador de la TV, si el firmware conserva el modo de desarrollador web, abre `hisense://debug` e introduce la URL de la aplicación. La disponibilidad y el flujo exacto dependen de la versión de firmware/región; no es un instalador USB ni una certificación para VIDAA Store.
3. Comprueba flechas, OK, regreso, scroll del catálogo, búsqueda y reproducción de una URL de prueba compatible.

IMPORTANTE
Esta entrega es una aplicación web alojada para pruebas, no un paquete VIDAA firmado. No puedo garantizar la instalación como app del launcher hasta validar el firmware concreto del televisor y el método de despliegue habilitado en él. La versión VIDAA U9 y el modelo 50A65NV orientan el diseño, pero el navegador/firmware puede variar.
